# proctore

A clean one-page site for proctore.com, built with Next.js, TypeScript, Tailwind CSS, and the App Router.

## Run locally

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Editing content

Most site content is in `app/page.tsx`:

- `projects`
- `skillGroups`
- `links`

Global styling lives in `app/globals.css`.
